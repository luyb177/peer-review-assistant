# 独立运行与配置

## 1. 最终运行程序

当前交付为 1.1.0，含教师/学生文档附件。完整解压作业包，进入 03_运行程序/peer-review-assistant，双击 run.cmd。程序附 Java 17，不需要 IDEA、Maven、系统 Java 或 JAVA_HOME。不要只复制 JAR 后删除 runtime/config。

同一产品 JAR 已完成最终包真实 MySQL、真实 AI、全部必选与选做实测及新 JVM 持久化验证。详见《最终运行包实机验收》。本次仅同步文档，产品 JAR 未改。

## 2. 首次使用须自备服务

此包不携带维护者的 MySQL 密码、AI Key、教师密码或课程默认服务。登录页可直接打开“连接配置”。先配置可用 MySQL，AI 可以关闭；新空专用库再初始化教师，按需要选择合成演示数据。

数据库账号不是应用登录账号。程序不会因显示登录页而自动发起 AI 请求。没有自己的服务时可以阅读设计和测试材料，但不能据此声称数据库业务已在该电脑完成连接。

## 3. MySQL

1. 在 MySQL 页填专用库 JDBC 地址、账号、密码及必要 TLS CA。
2. “测试连接与结构”只检查草稿，不切换当前配置。
3. “保存并切换”检查结构；缺库/表且权限允许时准备，已知旧字段可增量补齐。
4. 结构冲突拒绝切换，不 DROP/TRUNCATE 或覆盖数据；由管理员迁移，勿删库重建。
5. 正常业务用专用库必要读写权限；自动建库/表需相应 CREATE/REFERENCES，字段升级需 ALTER。不要分发 root 账号。
6. 成功切换后重新登录；原库数据不会自动迁移。新空库从登录页“初始化专用库”设置教师。

CA 路径相对于 config，也支持绝对路径。TLS 参数以自己的服务器证书为准，不要关闭证书检查。旧版迁移见 sql/01-review-version.sql 与 sql/02-document-attachments.sql。

## 4. AI

AI 页支持 anthropic 与 openai-compatible，地址、模型和 Key 须相互匹配。“测试 AI 连通性”只做带认证的模型列表 GET，不生成内容、不发送作业，也不证明指定模型推理一定成功。

关闭“启用 AI”仍可人工评分。只有显式选择优先使用环境变量才由 PEER_REVIEW_AI_KEY 覆盖当前方案 Key。外部地址必须 HTTPS，仅精确回环 localhost、127.0.0.1、::1 允许 HTTP；其他电脑不能直接访问本机回环网关。

实际生成在评审窗口经外发/费用确认后触发，可能计费。失败可继续人工互评；不要盲目重复生成。

## 5. 文件与多方案

config/application.example.properties 是无凭据样例。保存成功后当前设置位于 config/application.properties；分别保存的数据库/API 方案位于 config/profiles/*.local.properties。两类凭据独立，不把 AI Key 存进数据库方案。

读取方案只填草稿，通过验证并保存后才生效。无效草稿或保存失败不覆盖原活动配置。MySQL DDL 不是全部语句整体事务，权限中断时可能已有部分空表，应修复权限后重试，不清库。

本地配置为明文，限制文件权限；填写了自己的凭据后不要转发整个运行目录。数据库备份需数据库流程，复制客户端不会备份 MySQL 数据。
