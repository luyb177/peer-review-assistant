# 测试说明

## 最近一次实际验证

2026-10-15 在 Windows 11、JetBrains Runtime 25 上执行 Maven `test`，编译目标为 Java 17：**53 项，0 失败、0 错误、0 跳过，BUILD SUCCESS**。

包含人工评分按钮事件验证与五个真实 Swing 窗口的离屏渲染。JDK 25 对部分依赖的 native access/Unsafe 给出兼容性警告，不影响本次测试通过；尚未另行在 JDK 17 运行时验证。

## 运行

在项目根目录使用 JDK 17+ 和 Maven：

```bash
mvn test
```

本轮不执行 `package`，不构建 JAR 或提交压缩包。

## 自动化范围

| 测试类 | 内容 |
|---|---|
| ScoreCalculatorTest | 不同分值区间归一化、满分/零分、舍入、权重、缺项/多项、重复 ID、越界与精度 |
| RandomAllocatorTest | M=2—16、所有有效 N、多组随机种子，检查任务总量、无自评、不重复、负载均衡；无效名单与人数 |
| PeerReviewServiceTest | 完整互评闭环、提交更新、时间边界、权限、盲评、统计、规则冻结、CRUD、重复评分/分配并发 |
| UtilitiesTest | 密码随机盐及校验、组合筛选、正则错误、CSV 转义、本地配置、认证、重复初始化保护 |
| AiAndTransactionTest | 禁用/非 HTTPS AI 在请求前失败；提示词包含规则且不带身份字段；参考意见不落成人工评分；SQL/运行时异常整体回滚 |
| ScoringPolicyTest | 注入策略同时用于预览与正式评分，重构行为保持 |
| AiEndpointTest | 精确回环 HTTP 放行、远程 HTTPS 要求、身份/查询参数拒绝、网关回退配置 |
| InitializationServiceTest | 表已由管理员建齐时不执行 DDL，不要求运行账号拥有 CREATE 权限 |
| SwingPreviewTest | 在 EDT 构建真实登录、教师、学生、评分、发布窗口并离屏渲染；评分框初始为空 |

H2 是 test-only 依赖，使用 MySQL 兼容模式跑 SQL 和事务集成测试。产品运行没有 H2 驱动，也没有内存模式兜底。

`RandomAllocatorTest` 的一项测试方法内部覆盖多种规模和随机种子；JUnit 的方法数不等于内部断言或输入组合数量，不夸大成多个独立测试用例。

## 输出

- `target/surefire-reports/`：JUnit 实际结果。
- `target/ui-preview/`：桌面环境的离屏渲染图；不是对实际 MySQL 联机使用的截图，也不是 WindowBuilder 使用截图。
- 无图形环境会跳过 Swing 渲染测试，不把跳过算通过。
