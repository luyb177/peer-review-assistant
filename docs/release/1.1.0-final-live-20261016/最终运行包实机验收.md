## 中断与修复

本次存在三次验收驱动中断，均保留原记录，没有把中断报告改称一次连续通过：

1. 表格刷新后选中行被清除，新增的重复分配步骤未重新选行。已补选行，在同一已分配批次恢复，未重复建课或重复调用 AI。
2. 编辑作业含评分表与附件表，新增驱动误选评分表，产品提示先选附件。已按附件组件定位；仅重建该批尚无提交的临时作业，评分记录保留。
3. N=1 的两条任务已生成，旧驱动把成功提示固定为六条而误报。已按场景核对数量，直接恢复已分配但未评分的两条任务，不重复分配。

另修正配置标签定位，只填写可见标签，避免在 AI 页填写到隐藏的 MySQL 同名字段。修改仅涉及测试驱动、运行脚本及说明，产品 JAR 和业务源码未改。恢复后的相关步骤和整套业务结果均已通过。
