# 桌面界面设计

## 设计方向

面向课堂教师和学生，重点是让「规则、参考、人工决定」在同一流程中保持清楚的边界，而不是设计成聊天机器人或 Web 管理模板。

- 正文墨绿 `#203A35`，操作强调 `#236A56`，次要文字 `#596B65`。
- 工作区浅灰绿 `#F4F7F5`，阅读区白色 `#FFFFFF`，登录说明区 `#E6F0E9`。
- Windows 使用 Microsoft YaHei UI，正文 13px，窗口标题 22—28px，分节 16—18px。
- 左对齐、清晰标签、表格优先；保留原生键盘焦点和可调整分隔面板。

## 交互结构

```text
角色和姓名                                      刷新 / 密码 / 配置 / 退出
课程筛选 | 作业筛选 | 任务状态 | 正则搜索
课程 / 作业 / 提交 / 互评 / 统计 / 学生账号 / 日志（教师）
[当前标签页操作]
[可排序、可选择的业务表格]
状态说明                                       AI 仅供参考
```

评审窗口采用「左侧阅读、右侧人工评分」；左侧再分提交原文和 AI 参考，两者与右侧评分输入不自动联动。

## 有意保持的克制

- 不加入无业务意义的统计卡片、图表、动画或聊天气泡。
- 不给评分框预填 AI 分数；人工输入初始为空。
- 数据库和网络请求使用 SwingWorker，失败后恢复窗口操作。
- AI 失败恢复原参考文本，已填写的人工内容不清空。
- 不把浏览器页面伪装成 Swing；所有界面均为真正的 Swing 组件。

## WindowBuilder 说明

当前界面使用手写 Swing + FlatLaf，在 IDEA 中维护。**尚未实际操作 Eclipse WindowBuilder，不能把当前代码或离屏渲染图当成 WindowBuilder 使用证据。** 若教师要求使用该可视化工具，需后续按要求操作和记录。
